# G^2 Game Hub

ゲーム紹介サイト（Astro）とゲームランチャー（Tauri v2）のコードです。ゲームとイベントのデータは、別の非公開リポジトリで管理します。

```bash
npm ci --ignore-scripts
npm run dev        # サイト
npm run launcher   # ランチャー
```

詳しくは [docs](docs/index.md) を読んでください：[仕組み](docs/architecture.md)・[運用](docs/operations.md)・[ランチャーの使い方](docs/launcher.md)・[コードの構造](docs/code.md)
